НОВАЯ СМЕНА

Запустим производство?

Сервер уже готов принимать события. Выполните эту команду в терминале из папки проекта — смена появится в панели автоматически.

python3 -m scripts.demo --url http://127.0.0.1:4001 --delay 0.03

Для зачётного прогона подключите публичный адрес сервиса в кабинете арены.
